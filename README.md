The site, which this repository is the basis for, provides a compact entry point to the thesis and to selected learning material on event-driven processes, reliability, replay, retention, settlement, and related design concerns.

Github pages deployed site: [TO come]

## About

The companion site is intentionally minimal. It is meant to make the thesis easier to access and to collect a small set of useful references for readers who want to explore the surrounding ideas in more depth.

The thesis itself is linked from the site, together with the empirical suite repository.

## Contents

The site includes the thesis abstract, links to the thesis and empirical suite, and a curated Learn More section with books, essays, papers, talks, and pattern references.
